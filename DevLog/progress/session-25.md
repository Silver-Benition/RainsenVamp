## 下个会话优先待办

1. **武器实际挂点与瞄准**：当前所有武器逻辑根挂在玩家中心，并非均匀分布的独立持武槽；只有环绕实体分布在圆周。初始瞄准沿用移动方向，没有自动锁敌。需下一轮先确定挂点、目标选择与攻击方向规则再实现。
2. **近战动作**：当前从玩家上方 90° 开始，按最后左右朝向向一侧扫过配置弧度；细剑和长枪也复用挥击，并非真正刺击。统一检查图像朝向、根部位置、挥击/刺击及判定一致性。
3. **棱晶飞梭已知未完成效果**：配置为 `Tracking` 弹射，但当前运行分支仅消耗次数，没有实际转向；“追踪弹射”仍是设计目标。后续修复必须补命中后转向与后续命中的行为测试，不能仅检查生成和回池。
4. **道具 Debug 继续验收与完善**：F7 卡死原因已修复并有窗口测试，但用户明确将目前道具 Debug 留到下一会话继续。先复核用户实际操作及尚存问题，再改进；不把本次自动化通过当作全部 Debug 诉求关闭。
5. 数值试玩：裂纹单镜范围代价、赤铜齿轮净收益、零再生下负面收益、专精构筑的无效代价及叠满收益。保留已审阅值，不在归档中重新平衡。
6. 弩/枪专属弹体、香炉表现、最终图标和动画，以及本地化、真实设备性能与全流程平衡仍待后续制作或验收。
