## 关键运行链路

```text
敌人死亡
  -> 原有 1% 宝箱掉落判定
  -> PoolManager 生成正式 TreasureChestPickup
  -> 0.5 秒内关闭 Collider2D，保证出生重叠时仍可辨认
  -> 保护结束后玩家触发拾取
  -> LevelUpManager.GrantRandomChestReward()
  -> 原有合法武器候选、容量与权重规则完成结算
  -> ChestRewardGranted(武器、最终等级、是否首次获得)
  -> TreasureChestRewardToastUI 排队展示来源
  -> PoolManager 播放并回收金色开启爆闪
```

反击脉冲仍保持逻辑与表现分离：机制运行时先用既有 Physics2D 非分配查询结算伤害，再请求池化 `AbilityPulseVfx` 播放正式环形 Sprite。VFX 的缩放和透明度不会反向影响伤害半径。
