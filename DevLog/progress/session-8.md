## 二、当前五类武器 MVP

| 武器 | 运行类型 | 当前行为 | 主要升级维度 |
|---|---|---|---|
| 火球术 | Projectile | 沿瞄准方向直飞，可多发、穿透和弹射 | 伤害、冷却、数量、速度、穿透、弹射 |
| 守护光环 | Aura | 维持一个跟随玩家的池化伤害区域 | 伤害、范围、伤害间隔 |
| 旋刃 | Orbiting | 多把小刀按共享相位均匀环绕玩家 | 数量、伤害、半径、角速度 |
| 飞斧 | Lobbed | 只向上半平面投掷，自转并按重力弹道飞行 | 伤害、冷却、数量、穿透、散射、自转 |
| 雨伞挥击 | Melee | 从玩家头顶起手，按面向向左右完成扇形挥击 | 伤害、冷却、范围、弧度、判定时间 |

五种武器均使用 WeaponDataSO 的五级配置和对象池实体。LevelUpManager 根据 WeaponDataSO.runtimeType 创建正确的运行时脚本，升级卡不再重复保存武器类型。

## 三、飞斧最终弹道状态

- 投掷初速度由“玩家发射瞬间的 Rigidbody2D 速度快照 + 上半平面投掷方向 × 投掷力度”组成。
- 位置使用确定性公式直接计算，不使用逐帧物理积分，因此轨迹不随帧率漂移。
- 低角度飞斧倾向从左右离屏；高角度飞斧会先上升、竖直速度归零，再向下坠落。
- 飞出视口顶部时不会立即回收，完全离开左右或下方边界时回收。
- 五级当前统一使用投掷力度 5、下坠重力 3、最大生命周期 7 秒。
- 老大最终测试反馈为“稍微好一些，仍有一些瑕疵，但不影响继续开发”。该问题保留为后续纯手感调优，不视为本次阻塞项。

## 四、武器配置工作流

### 批量配置

1. 在 Unity 菜单打开 Tools / RainsenVamp / Weapon Config Studio。
2. 点击“载入默认平衡表”，读取 Assets/Data/WeaponBalance.csv；也可以选择 Assets 内或外部 CSV。
3. 点击“预览并校验”，确认路径、运行类型、Prefab 组件、等级和安全数值均无错误。
4. 点击“导入 / 更新资产”，创建或更新 Assets/Data 下同名 WeaponDataSO 与 UpgradeDataSO。
5. 如需把本轮升级卡写入当前场景，再单独点击“同步当前场景升级池”并保存场景。

### 单资产配置

- 在工作台选择 WeaponDataSO，可按 runtimeType 只显示本类型相关字段。
- 支持增删等级、编辑配套升级卡和一键创建同名武器/升级资产对。
- Lobbed 类型的 projectileSpeed、lifeTime、lobGravity 在 GUI 中分别显示为“投掷力度”“最大生命周期”“下坠重力”。
- CSV 新字段使用 lobGravity；解析器仍接受旧表头 arcHeight 作为一次性迁移兼容。

## 五、开发测试入口

- 在 Editor 或 Development Build 运行游戏后按 F8 打开 Weapon Debug 面板。
- 每把武器提供 Lv.1 至最大等级按钮，可直接获得武器或连续升级到目标等级。
- 面板调用正式的 LevelUpManager 授予路径，不维护第二套武器创建逻辑。
- 调试操作只允许升级，不支持降级、移除或重置；需要重置时重新进入 Play Mode。
- 该功能由条件编译保护，不进入普通 Release Build。
